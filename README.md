## 🌟 Overview

**TP x STUDIO** (`https://tpxstudio.vercel.app/`) is a premier digital studio and cyber-architecture hub. Built with a signature **Obsidian Gold** luxury aesthetic, the platform showcases high-performance technical engineering, self-hostable BaaS backends, low-latency game server clusters (<12ms in Indian datacenters), production-grade 3D Blockbench voxel packs, and viral social media video production.

---

## 🚀 Key Features

- **🎨 Obsidian Gold Dark Glassmorphism**: High-contrast, luxury UI with hardware-accelerated fluid golden weave canvas ribbon backdrop.
- **⚡ 100/100 Google Lighthouse Rating**: Sub-second First Contentful Paint (FCP), zero layout shifts (CLS), and optimized asset pipeline.
- **📱 Fully Phone & Tablet Optimized**: Responsive touch targets, fluid horizontal tab bars, and glitch-free fixed viewport positioning.
- **🌍 Built-in Multilingual Engine (i18n)**: Seamless instant switching across **English (EN)**, **Hindi (HI)**, **Japanese (JA)**, **Spanish (ES)**, and **German (DE)** with `localStorage` state persistence.
- **🛠️ Interactive Service Specs Modal**: Tap any service card to view a high-resolution 3-image production gallery, technical specification breakdown, and direct WhatsApp booking protocol.
- **💬 Swappable Client Stories**: Carousel testimonial system with `<` and `>` touch controls.
- **📲 Instant WhatsApp Project Protocol**: Integrated onboarding builder mapping budget, service, and timeline directly to WhatsApp chat.
